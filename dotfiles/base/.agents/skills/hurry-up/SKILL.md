# Hurry up

The owner prefers completion now over more certainty. Change the remaining work, not just the tone of progress updates.

- **Freeze scope.** Finish the agreed deliverable. Drop optional polish, new hardening, refactors, audits, and follow-up work. Reuse decisions already made.
- **Qualify preliminary measurements.** Use fewer benchmark samples when time is the constraint and label the result preliminary. Stop optional work already running when it can be interrupted safely.
- **Preserve the real boundaries.** Urgency does not authorize new external actions, data loss, hidden contract changes, or false claims. If a binding requirement cannot be waived, finish the useful work and name the remaining proof instead of claiming it.
- **Close the task.** Do not replace dropped checks with a plan, ticket campaign, another review, or a permission question. Leave the requested result usable and stop once the minimum useful verification is complete.

**The test:** optional rigor has actually been cut, and the requested deliverable is finished with an honest account of the evidence.

**Report:** what is done, what was skipped or remains uncertain, and any decision that truly blocks completion. Keep it short.
