# ELI5

Explain it so a five-year-old could follow, and stop. Do not edit files, run commands, or start delegated work in this turn. Reading code or docs to get the facts right is fine.

Explain the topic the user names. With no topic, explain your last reply.

- Use short, plain words. Replace each technical term with what it does, and say the term only if the user will meet it again.
- Give one everyday comparison from home, school, food, or play, and keep it to the point. Do not stack analogies.
- Say what it is, what it is for, and one example of it happening.
- Write at most six short sentences in plain prose. No headings, bullets, tables, code, or links.
- Be accurate. Leave detail out rather than saying something false, and do not talk down.

End with one line offering to go deeper.

**Report:** the explanation, nothing else.
