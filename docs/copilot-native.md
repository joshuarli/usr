# Copilot CLI / MAI pilot

Status: **configuration candidate, not runtime qualified**. This branch adds a native-only Copilot parent without changing existing bridge provider order, other harness defaults, model bans or subscriptions. No authenticated inference, subscription purchase, installation or host sync was performed. Do not treat the proposed IDs or effort levels as attested.

## Configuration

The normal shared contract is linked as `~/.copilot/copilot-instructions.md`; Copilot discovers the existing `~/.agents/skills/`. Do not copy the corpus. The typed policy generates four user agents under `~/.copilot/agents/`. Settings opt out of auto-update, remote export, remote sessions and IDE auto-connect, set the proposed MAI parent, and disable documented built-in agents. The native `task` tool itself is distinct from the built-in agent named `task`; verify this distinction. Explicitly request the named custom agents. Children have strict tool-group lists, no automatic inference, and must not delegate. The depth setting is plan-dependent; verify it. No bridge MCP server is registered for Copilot; the existing scope checker remains available to the parent.

Native writers get the same worktree, scope, proof and parent review requirements as orchestrate. The scout must have no shell, editing, external mutation or delegation capability.
